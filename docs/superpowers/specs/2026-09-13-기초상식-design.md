# 기초상식 — 설계 문서

작성일: 2026-09-13

## 1. 개요

기초 상식을 매일 조금씩 익히는 개인용 퀴즈 게임. 공부하는 느낌이 아니라 게임을 해서 상금을 벌고 레벨을 올리는 느낌을 목표로 한다. 예능 '유퀴즈'의 상금·칭호 정서를 차용한다.

- **형태**: 폰 화면 우선 웹앱(PWA). 나중에 무료 호스팅에 올려 홈화면에 설치해 쓸 수 있게 한다.
- **사용자**: 본인 한 명. 계정·로그인·서버 없음. 기록은 브라우저 localStorage에만 저장한다.
- **문제**: 고정 문제은행. 저장소에 JSON/TS 데이터로 포함하며 오프라인에서 동작한다.
- **톤**: 흰 배경 + 초록 포인트의 밝은 파스텔. 두툼한 버튼(아래쪽 테두리가 두꺼운 형태).

## 2. 비목표

다음은 이번 범위에서 명시적으로 제외한다.

- 연속 출석(스트릭), 목숨/하트, 문제별 제한시간 — 매일 부담 없이 들어올 수 있어야 한다는 요구에 따라 전부 제외
- 단답 입력형 문제 — 띄어쓰기·한자·오타로 오채점이 나기 쉬움
- 로그인, 서버, 랭킹, 친구 기능
- AI 실시간 문제 생성
- 앱스토어/웹스토어 등록

## 3. 콘텐츠

### 3.1 카테고리 (7개)

| id | 이름 |
|---|---|
| `korean-history` | 한국사 |
| `world-history` | 세계사 |
| `science` | 과학 |
| `math` | 수학 |
| `music` | 음악 |
| `art` | 예술 |
| `current-affairs` | 시사 |

### 3.2 분량

카테고리마다 **3단계**(입문 `basic` / 중급 `mid` / 상급 `advanced`) × **스테이지 3개** × **5문제**.

- 카테고리당 45문제, 전체 **315문제**, 전체 **63스테이지**
- 한 스테이지는 1~2분 분량

문제 형식은 4지선다(`choice`)와 OX(`ox`)를 섞는다. 스테이지 5문제 중 OX는 0~2문제를 권장한다.

### 3.3 시사 카테고리 정책

고정 문제은행이므로 시효성 있는 문제는 쓰지 않는다. "현재 ○○는 누구인가", "올해 ○○ 수치는" 같은 문제는 몇 달 뒤 오답이 된다.

대신 상식으로 굳은 제도·용어·기구를 다룬다. 예: 인플레이션, 기준금리, GDP, 최저임금 제도, 국회의 입법 절차, NATO·UN·WHO의 역할, 탄소중립, 기축통화.

모든 문제에 집필 시점(`writtenAt`, `YYYY-MM`)을 기록해 나중에 낡은 문제를 찾아낼 수 있게 한다.

### 3.4 문제 데이터 모델

```ts
type CategoryId =
  | 'korean-history' | 'world-history' | 'science'
  | 'math' | 'music' | 'art' | 'current-affairs';

type Tier = 'basic' | 'mid' | 'advanced';

type Question = {
  id: string;            // '<카테고리약어>-<단계약어>-<2자리>' 예: 'kh-b-01'
  category: CategoryId;
  tier: Tier;
  stage: 1 | 2 | 3;
  type: 'choice' | 'ox';
  prompt: string;        // 문제. 구어체 질문형 ('~일까요?')
  choices: string[];     // choice는 4개, ox는 ['O', 'X']
  answerIndex: number;   // 0-based
  hint: string;          // 방향만 알려주고 정답을 누설하지 않는 한 줄
  explanation: string;   // 정답 확인 후 보여주는 2~3문장 해설
  writtenAt: string;     // 'YYYY-MM'
};
```

id 약어:

| 카테고리 | 약어 | | 단계 | 약어 |
|---|---|---|---|---|
| 한국사 | `kh` | | 입문 | `b` |
| 세계사 | `wh` | | 중급 | `m` |
| 과학 | `sc` | | 상급 | `a` |
| 수학 | `ma` | | | |
| 음악 | `mu` | | | |
| 예술 | `ar` | | | |
| 시사 | `ca` | | | |

번호는 단계 안에서 01부터 15까지 이어진다(1스테이지 01~05, 2스테이지 06~10, 3스테이지 11~15). 예: `sc-a-13`은 과학 상급 3스테이지의 세 번째 문제.

집필 규칙:

- `prompt`는 진행자가 읽어주는 말투로 쓴다. 예: "조선왕조실록을 보관했던 창고를 무엇이라 부를까요?"
- `hint`는 정답 단어와 그 동의어를 포함하지 않는다. 예: 정답이 '사고(史庫)'일 때 힌트는 "기록을 불이나 전쟁에서 지키려고 여러 곳에 나눠 두었어요."
- `explanation`은 정답 이유를 설명하고, 가능하면 기억에 남을 한 가지 사실을 덧붙인다.
- 오답 보기는 같은 범주에서 고른다(인물 문제면 오답도 인물). 길이도 비슷하게 맞춰 정답이 눈에 띄지 않게 한다.

## 4. 게임 규칙

### 4.1 해금

- 스테이지는 단계 안에서 순서대로 열린다. 1스테이지는 처음부터 열려 있다.
- **스테이지 클리어 = 5문제 중 3문제 이상 정답.** 클리어하면 다음 스테이지가 열린다.
- 한 단계의 스테이지 3개를 모두 클리어하면 다음 단계의 1스테이지가 열린다.
- 각 카테고리의 입문 1스테이지는 처음부터 열려 있다. 즉 7개 카테고리를 처음부터 아무 순서로 시작할 수 있다.
- 클리어한 스테이지는 언제든 다시 풀 수 있다(재도전).

### 4.2 상금

| 항목 | 금액 |
|---|---|
| 처음 맞히는 문제 | 10,000원 × 단계 배수 |
| 전에 맞힌 적 있는 문제 | 위 금액의 절반 |
| 단계 배수 | 입문 1배 / 중급 1.5배 / 상급 2배 |
| 스테이지 첫 클리어 | +20,000원 (스테이지당 1회) |
| 스테이지 5문제 만점 | +30,000원 (스테이지당 1회) |
| 오늘의 볼게임 완료 | +30,000원 (하루 1회) |
| 오답노트에서 정답 | +5,000원 (단계 배수·절반 규칙 미적용) |

감액 기준은 스테이지가 아니라 **문제 단위**다. 한 번 맞힌 문제는 이후 어디서 다시 나와도(스테이지 재도전, 볼게임, 오답노트 복습) 절반만 지급한다. 아직 맞혀본 적 없는 문제는 재도전에서도 정가를 지급한다 — 약한 부분을 메우는 쪽이 이득이어야 한다.

보너스를 전부 1회로 제한하고 감액을 문제 단위로 두는 이유: 쉬운 입문 스테이지나 볼게임을 무한 반복하는 것이 가장 이득이 되면 진행 동기가 사라진다. 볼게임은 횟수 제한이 없으므로 이 규칙이 특히 중요하다.

뱃지 판정용 만점 횟수(`perfectCount`)는 상금 보너스와 별개로, 만점을 낸 판마다 재도전을 포함해 누적한다.

상금은 두 곳에 기록한다.

- **누적 상금 (`totalPrize`)** — 평생 누적. 레벨 산정 기준이며 절대 줄지 않는다.
- **지갑 (`wallet`)** — 쓸 수 있는 잔액. 상점 구매 시 여기서만 차감한다.

상금을 벌면 두 값이 함께 오르고, 쓰면 지갑만 줄어든다.

### 4.4 오늘의 볼게임

여러 카테고리를 섞은 5문제 한 판. 처음부터 항상 열려 있다.

- 문제는 **현재 열린 스테이지들의 문제 풀**에서 5개를 뽑는다.
- 추출 가중치: 오답노트에 있는 문제 3배, 아직 풀지 않은 문제 2배, 이미 맞힌 문제 1배.
- 한 판 안에서 같은 문제는 중복되지 않는다.
- 문제별 상금은 4.2의 규칙을 그대로 따른다(해당 문제의 단계 배수, 이미 맞힌 문제는 절반).
- 완료 보너스 30,000원은 **하루 1회**만 지급한다. 그 이후에도 계속 플레이할 수 있으나 보너스는 없다(문제 상금은 지급).
- 볼게임은 스테이지 클리어 판정과 무관하다. 틀린 문제는 오답노트에 등록된다.

### 4.5 오답노트

- 문제를 틀리면 해당 문제 id가 오답노트에 자동 등록된다. 패스한 문제도 등록된다.
- 오답노트 화면에서 모아 다시 풀 수 있고, **맞히면 오답노트에서 제거**된다.
- 오답노트 정답은 5,000원을 지급한다(단계 배수 미적용).
- 오답노트 풀이는 스테이지 클리어 여부에 영향을 주지 않는다.
- 오답노트에서 맞힌 문제도 `questionStats`에 정답으로 기록되므로, 이후 그 문제는 절반 규칙의 대상이 된다.
- 오답노트에서 빠지는 것은 **오답노트 복습으로 맞혔을 때만**이다. 스테이지 재도전이나 볼게임에서 같은 문제를 맞혀도 오답노트에는 남는다.
- 패스한 문제는 통계에서 오답으로 집계한다(답을 맞히지 못했으므로).

### 4.6 뱃지 (18개)

| 분류 | 뱃지 | 조건 |
|---|---|---|
| 카테고리 완주 (7) | 한국사/세계사/과학/수학/음악/예술/시사 마스터 | 해당 카테고리 9스테이지 전부 클리어 |
| 단계 졸업 (3) | 입문 졸업 / 중급 졸업 / 상급 졸업 | 7개 카테고리의 해당 단계를 전부 클리어 |
| 만점 (3) | 첫 만점 / 만점 10회 / 만점 30회 | 스테이지 만점 누적 횟수 |
| 오답 (2) | 오답 10개 극복 | 오답노트에서 정답 처리한 문제 누적 10개 |
| | 오답노트 비우기 | 오답이 1개 이상 쌓인 적이 있고, 오답노트가 0개가 됨 |
| 볼게임 (2) | 볼게임 7회 / 30회 | 볼게임 완료 누적 횟수 |
| 레벨 (1) | 척척박사 | Lv.10 도달 |

뱃지는 획득 시점에 결과 화면에서 연출로 알려준다.

미획득 뱃지도 조건과 함께 흐리게 보여주고, **횟수로 세는 뱃지는 진행률을 함께 표시한다** — 만점 10·30회, 오답 10개 극복, 볼게임 7·30회는 `3/10` 형태로, 카테고리 마스터와 단계 졸업은 `클리어 6/9` 형태로, 오답노트 비우기는 `남은 오답 8개`로 표시한다. Lv.10 뱃지는 `Lv.7`처럼 현재 레벨을 보여준다.

### 4.7 상점

**소모 아이템** — 인벤토리 없이 퀴즈 화면에서 누르면 즉시 지갑에서 결제되고 바로 발동한다.

| 아이템 | 가격 | 효과 |
|---|---|---|
| 반반 찬스 | 20,000원 | 오답 보기 2개를 지운다. OX 문제에서는 비활성 |
| 한 줄 힌트 | 30,000원 | 문제의 `hint`를 보여준다 |
| 패스 | 15,000원 | 문제를 건너뛴다. 정답으로 세지 않고, 오답노트에 등록된다 |

한 문제에서 아이템은 종류별로 1회씩만 쓸 수 있다. 잔액이 부족하면 버튼이 흐려지고 눌리지 않는다.

**영구 아이템** — 상점 화면에서 구매하고 프로필에서 적용한다.

| 종류 | 항목 | 가격 |
|---|---|---|
| 테마 | 기본 파스텔 | 무료 |
| | 살구빛 | 300,000원 |
| | 라벤더 | 500,000원 |
| | 바다 | 700,000원 |
| | 야간모드 | 1,000,000원 |
| 아바타 | 🙂 🐣 🦉 | 무료 |
| | 🦊 | 200,000원 |
| | 🐼 | 400,000원 |
| | 🦁 | 600,000원 |

칭호는 레벨에 따라 자동으로 부여되므로 판매하지 않는다.

## 5. 화면

### 5.1 홈

- 상단: 아바타, 레벨과 칭호, 누적 상금, 지갑 잔액
- 큰 버튼: **오늘의 볼게임 시작** (오늘 보너스를 이미 받았으면 "한 판 더" 표시)
- 줄 항목: 이어서 하기 / 뱃지(획득 수) / 오답노트(문제 수) / 상점
  - 이어서 하기: 가장 최근 플레이한 카테고리에서 도전 가능한 다음 스테이지로 간다. 기록이 없으면(첫 실행) "한국사부터 시작하기"로 표시한다. 해당 카테고리를 모두 깼으면 진행 중인 다른 카테고리를 가리킨다.
- 카테고리 가로 스크롤 칩 → 누르면 카테고리 상세로 이동
- 하단: 카테고리 전체 보기, 프로필·설정

### 5.2 카테고리 목록

7개 카테고리를 아이콘·이름·진행률 바(클리어 스테이지 n/9)와 함께 나열한다.

### 5.3 카테고리 상세

- 상단 탭: 입문 / 중급 / 상급. 잠긴 단계는 흐리게 표시하고 누르면 해금 조건을 알려준다.
- 선택된 단계의 스테이지 3개를 카드로 나열한다. 각 카드에 스테이지 제목, `5문제`, 최고 기록(`최고 4/5`), 상태(클리어 / 도전 가능 / 잠김 + 조건)를 표시한다.

### 5.4 퀴즈

- 상단: 카테고리·단계명, 진행도(`3/5`)와 진행 바, 나가기
- 문제와 보기(4지선다는 4개 버튼, OX는 O/X 두 개 큰 버튼)
- 하단: 아이템 버튼 3개(✂️ 반반 · 💡 힌트 · ⏭️ 패스)와 지갑 잔액. 각 버튼에 가격을 작게 표시한다. 잔액 부족이면 흐리게(비활성), 이미 쓴 아이템은 회색 `사용됨`으로 바뀐다
- 반반 찬스를 쓰면 오답 보기 2개가 취소선과 함께 흐려지고 누를 수 없게 된다. 힌트를 쓰면 문제 아래에 노란 힌트 카드가 열린다
- 보기를 누르면 즉시 정답/오답 표시와 해설 카드가 뜨고, **계속** 버튼으로 다음 문제로 간다. 정답 보기는 초록, 고른 오답은 빨강, 정답은 항상 함께 표시한다.
- 중간에 나가면 그 판은 기록되지 않는다(상금·오답노트·클리어 반영 없음). 단, 이미 쓴 아이템 비용은 환불되지 않는다 — 나가기를 누를 때 아이템을 썼다면 확인을 한 번 받는다.

### 5.5 결과

- 맞은 개수와 클리어 여부
- 상금 내역을 한 줄씩 쌓아 보여주고 합계를 강조한다: `정답 5개 (중급 1.5배) 75,000원` / `첫 클리어 보너스 20,000원` / `만점 보너스 30,000원` / `합계 +95,000원`
- **아이템 사용 비용은 결과 화면에 표시하지 않는다.** 아이템은 쓰는 순간 지갑에서 차감되므로, 결과 화면에 다시 적으면 한 번 더 빠지는 것처럼 읽힌다. 이 판의 상금만 보여준다.
- 새 뱃지가 있으면 메달과 이름을 카드로 보여주고, 레벨업이 있으면 이어서 5.10 오버레이를 띄운다
- 버튼: 다시 하기 / 다음 스테이지 / 나가기

### 5.6 오답노트

틀린 문제를 카테고리별로 묶어 나열한다. **복습 시작**을 누르면 최대 10문제씩 풀이 화면으로 간다. 맞히면 목록에서 사라진다. 비어 있으면 빈 상태 화면을 보여준다.

### 5.7 뱃지

18개를 그리드로 보여준다. 한 줄에 3개(폰 기준), 원형 메달 + 이모지 + 이름.

- 획득: 분류별 색 그라데이션 메달, 안쪽에 흰 테두리, 아래에 획득일
- 미획득: 회색 점선 원 안에 회색조 이모지, 이름도 흐리게, 아래에 조건과 진행률(4.6 참고)

### 5.8 상점

소모 아이템(설명과 가격, 구매는 퀴즈 화면에서 한다는 안내)과 영구 아이템(테마·아바타, 구매/보유 상태) 두 묶음.

### 5.9 프로필·설정

- 레벨·칭호·누적 상금·지갑
- 통계: 카테고리별 정답률, 총 플레이 판 수, 만점 횟수, 볼게임 완료 횟수
- 테마·아바타 적용
- 전체 초기화(2단계 확인)

### 5.10 레벨업 연출

전체 화면 오버레이로 새 레벨과 칭호를 보여주고 탭하면 닫힌다.

## 6. 아키텍처

### 6.1 기술 선택

Vite + React + TypeScript. 화면이 10개고 상금·레벨·뱃지·오답노트 상태가 서로 엮이므로, 화면당 파일을 분리하고 타입으로 데이터 오류를 잡는 쪽이 장기적으로 수정이 쉽다. 라우팅은 React Router, 상태는 Context + reducer로 충분하다(외부 상태 관리 라이브러리 없음).

### 6.2 파일 구조


`domain/`은 React를 import하지 않는 순수 함수만 둔다. 입력은 저장 상태와 문제 데이터, 출력은 계산 결과뿐이다. 상금이 잘못 찍히거나 스테이지가 안 열리는 문제는 모두 여기서 발생하므로, 이 층만 테스트로 잠가두면 화면은 자유롭게 수정할 수 있다.

### 6.3 저장 스키마

localStorage 단일 키 `gs.v1.state`에 JSON으로 저장한다.

```ts
type SaveState = {
  version: 1;
  totalPrize: number;              // 누적 상금 (레벨 기준)
  wallet: number;                  // 지갑 잔액
  stages: Record<string, {         // 키: '<category>-<tier>-<stage>'
    cleared: boolean;
    bestCorrect: number;           // 최고 정답 수 0~5
    plays: number;
  }>;
  questionStats: Record<string, {  // 키: question id
    correct: number;
    wrong: number;
  }>;
  wrongNotes: string[];            // question id 목록
  wrongNotesResolved: number;      // 오답노트에서 맞힌 누적 개수
  wrongNotesEverAdded: number;     // 오답이 쌓인 적 있는지 판정용
  perfectCount: number;
  dailyGame: {
    lastBonusDate: string | null;  // 'YYYY-MM-DD'
    completed: number;
  };
  badges: { id: string; earnedAt: string }[];
  owned: { themes: string[]; avatars: string[] };
  settings: { theme: string; avatar: string };
  lastPlayed: { category: CategoryId; tier: Tier; stage: number } | null;
};
```

`version` 필드로 나중에 스키마가 바뀔 때 마이그레이션할 수 있게 한다. 저장 값이 없거나 깨져 있으면 기본 상태로 시작한다(앱이 죽지 않는다).

### 6.4 오류 처리

- localStorage 접근 실패(사생활 보호 모드 등): 메모리 상태로 계속 동작하고, 기록이 저장되지 않는다는 안내를 한 번 띄운다.
- 저장 JSON 파싱 실패: 기본 상태로 초기화하고 안내한다.
- 잠긴 스테이지로 직접 접근(URL 조작 등): 카테고리 상세로 돌려보낸다.
- 문제 데이터가 5문제보다 적은 스테이지: 개발 중 데이터 검증 테스트에서 실패하므로 런타임에서는 발생하지 않는다.

## 7. 테스트

Vitest를 쓴다. 두 종류를 둔다.

**규칙 테스트** (`domain/*.test.ts`)

- 상금: 단계 배수, 첫 클리어 보너스(스테이지당 1회), 만점 보너스(스테이지당 1회), 이미 맞힌 문제 절반 감액, 아직 못 맞힌 문제는 재도전에서도 정가, 오답노트 정답 정액
- 해금: 3문제 정답으로 클리어, 2문제면 미클리어, 단계 3스테이지 완료 시 다음 단계 해금
- 레벨: 임계값 경계(정확히 임계값일 때 레벨 오름), 최고 레벨 초과, 다음 레벨까지 남은 금액
- 뱃지: 18개 각각의 조건, 이미 획득한 뱃지를 중복 지급하지 않음
- 볼게임: 열린 문제만 뽑음, 5문제 중복 없음, 오답 문제가 더 자주 뽑힘, 보너스는 하루 1회
- 오답노트: 틀리면 등록, 패스도 등록, 맞히면 제거, 중복 등록 안 함
- 저장: 라운드트립, 빈 값·깨진 JSON 복구, 초기화

**문제 데이터 검증 테스트** (`data/questions.test.ts`)

315문제를 집필하는 동안 실수를 잡는 그물이다.

- 모든 문제 id가 유일하고 명명 규칙을 따름
- `choice`는 보기 4개, `ox`는 `['O','X']`
- `answerIndex`가 보기 범위 안
- `prompt`·`hint`·`explanation`이 비어 있지 않음
- `hint`에 정답 보기 문자열이 그대로 들어 있지 않음(정답 누설 방지)
- 보기 안에 중복 문자열 없음
- 카테고리마다 단계 3개 × 스테이지 3개가 모두 있고, 각 스테이지는 정확히 5문제
- 모든 문제의 `category`/`tier`/`stage`가 배치된 위치와 일치
- `writtenAt`이 `YYYY-MM` 형식

## 8. PWA

`vite-plugin-pwa`로 manifest와 서비스 워커를 생성한다. 앱 이름 "기초상식", 아이콘(192·512), 세로 고정, 오프라인 캐시(앱 셸과 문제 데이터 전체). 정적 파일만 있으므로 나중에 아무 무료 호스팅에 폴더째 올리면 폰 홈화면에 설치해 오프라인으로 쓸 수 있다.

## 9. 진행 순서

1. 프로젝트 뼈대: Vite + React + TS, 테마 CSS 변수, 라우팅, 저장 계층
2. `domain/` 규칙과 테스트 (문제 데이터 없이 가짜 데이터로)
3. 화면: 홈 → 카테고리 목록 → 카테고리 상세 → 퀴즈 → 결과
4. 문제 데이터 검증 테스트 + 한국사 45문제 집필
5. 과학 45문제 집필 → **여기서 실제로 폰에서 돌려보고 방향 점검**
6. 오답노트, 뱃지, 상점, 프로필 화면
7. 남은 카테고리 5개 문제 집필(세계사·수학·음악·예술·시사)
8. PWA 설정과 마무리
